# 🧪 Challenge

Now it's your turn!

Modify the program to compare **two bacterial genomes** instead of one.

## Tasks

- Add metadata for *Bacillus subtilis*.
- Store its:
  - Organism name
  - Strain
  - Genome size
  - Gene count
  - GC content

Then answer the following questions using Python:

1. Which organism has the larger genome?
2. Which organism has more genes?
3. Which organism has the higher GC content?

## Bonus Challenge

Store both genomes inside a list and display their information using a loop.

This exercise will strengthen your understanding of variables, dictionaries, lists, and loops while working with real biological data.
