# 🧬 Day 01 — Organizing Genome Metadata Using Python Variables

## 📖 Overview

Every bioinformatics analysis begins with organizing biological data.

Before performing genome annotation, sequence alignment, or comparative genomics, researchers first need to store important information about an organism in a structured way.

In this lesson, we use Python variables and basic data structures to organize metadata from the bacterial genome of **Escherichia coli K-12 MG1655**.

---

## 🎯 Biological Problem

A microbiology laboratory has completed the whole-genome sequencing of *Escherichia coli*.

Before beginning downstream analyses, researchers need to organize important information such as:

- Organism name
- Strain
- Substrain
- Genome size
- Gene count
- GC content

Instead of manually recording these values, we will use Python to organize them efficiently.
