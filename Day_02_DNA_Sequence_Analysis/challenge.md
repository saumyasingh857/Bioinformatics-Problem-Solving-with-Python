# 🧩 Challenge

A microbiology laboratory has sequenced a short DNA fragment from a bacterial genome. Before performing advanced analyses, the researchers need to extract basic information from the sequence.

Your task is to build a Python program that:

- Reads a DNA sequence from a text file.
- Validates that it contains only A, T, G, and C.
- Calculates sequence length.
- Counts the number of A, T, G, and C nucleotides.
- Calculates GC content and AT content.
- Detects the start codon and stop codon.
- Simulates transcription by converting DNA into RNA.
- Generates a scientific summary of the sequence.

This project introduces the use of Python string operations to solve real bioinformatics problems.
