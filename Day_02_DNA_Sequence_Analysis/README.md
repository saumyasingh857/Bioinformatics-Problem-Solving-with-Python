# 🧬 Episode 02 | DNA Sequence Analysis Using Python Strings

## 📖 Overview

DNA sequence analysis is one of the most fundamental tasks in bioinformatics.

Before advanced analyses such as sequence alignment, gene prediction, primer design, or genome annotation, researchers first examine the basic properties of a DNA sequence.

In this project, we use Python string operations to analyze a bacterial DNA sequence and extract biologically meaningful information.

---

## 🎯 Biological Problem

A researcher has sequenced a DNA fragment from a bacterial genome.

Before performing downstream analyses, the researcher wants to answer several important questions:

- What is the length of the DNA sequence?
- How many Adenine (A), Thymine (T), Guanine (G), and Cytosine (C) nucleotides are present?
- What is the GC content?
- Does the sequence begin with a start codon (ATG)?
- What would the RNA sequence look like after transcription?

Python allows us to automate these routine analyses quickly and accurately.
