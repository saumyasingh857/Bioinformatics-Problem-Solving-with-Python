# Challenge

A researcher has several DNA sequences and wants to compare their nucleotide composition.

Build a Python program that:

- Reads multiple DNA sequences from a file.
- Counts A, T, G, and C in each sequence.
- Calculates the percentage of each nucleotide.
- Identifies the most abundant nucleotide.
- Generates a clear composition report.

The goal is to use Python dictionaries to organize and analyze biological sequence data.
