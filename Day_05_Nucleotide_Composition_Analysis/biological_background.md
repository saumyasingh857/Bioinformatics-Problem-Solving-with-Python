# Biological Background

DNA is composed of four nucleotide bases:

- Adenine (A)
- Thymine (T)
- Guanine (G)
- Cytosine (C)

Nucleotide composition describes how frequently each base occurs within a DNA sequence.

Analyzing nucleotide composition can help researchers understand genome characteristics and compare different sequences.

In this project, Python dictionaries will be used to store and analyze the frequency of A, T, G, and C bases in multiple DNA sequences.
