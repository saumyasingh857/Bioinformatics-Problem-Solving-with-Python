# 🧬 Episode 05 | Nucleotide Composition Analysis

## Overview

DNA sequences contain four nucleotide bases: A, T, G, and C.

In this project, Python dictionaries are used to analyze the nucleotide composition of multiple DNA sequences.

## Biological Problem

A researcher wants to compare the nucleotide composition of several DNA sequences.

The program:

- Reads multiple DNA sequences
- Counts A, T, G, and C
- Calculates nucleotide percentages
- Identifies the most abundant nucleotide
- Generates a composition report
