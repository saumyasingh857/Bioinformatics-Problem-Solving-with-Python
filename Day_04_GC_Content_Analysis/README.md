# 🧬 Episode 04 | GC Content Analysis Using Python Functions

## Overview

GC content is an important characteristic of DNA sequence composition.

In this project, Python functions are used to calculate and classify the GC content of multiple DNA sequences.

## Biological Problem

A researcher wants to compare the GC composition of several DNA sequences.

The program:

- Reads DNA sequences from a file
- Calculates GC content
- Classifies GC content
- Reports sequence length
- Generates a final analysis report
