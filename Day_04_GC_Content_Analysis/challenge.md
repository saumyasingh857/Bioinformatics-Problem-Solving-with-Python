# Challenge

A researcher has several DNA sequences and wants to compare their GC content.

Build a Python program that:

- Reads multiple DNA sequences from a file.
- Calculates the GC content of each sequence.
- Uses a reusable Python function for the calculation.
- Classifies sequences based on their GC content.
- Produces a clear analysis report.

The main goal is to solve a biological sequence-analysis problem using reusable Python code.
