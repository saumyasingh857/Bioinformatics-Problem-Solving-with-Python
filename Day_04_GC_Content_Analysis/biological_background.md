# Biological Background

GC content is the percentage of guanine (G) and cytosine (C) bases in a DNA sequence.

GC content can be calculated as:

GC Content = ((G + C) / Total Bases) × 100

GC content is useful for understanding genome composition and can be used in comparative genomics, genome characterization, primer design, and other sequence-analysis tasks.

In this project, Python functions will be used to make GC-content calculation reusable for multiple DNA sequences.
